## “不限流量”有四种写法，先弄清自己买的是哪一种

搜这个词的人，心里想的往往是“随便跑、不额外收费”。市面上的产品实际分成几类，价格差距非常大。

**真不限速、不限量。** 奥地利厂商KernelHost的东京Edge VPS写明无月配额、不限速、不按TB收费，上行最高1Gbps，含3.2Tbps DDoS防护，起价€23.99/月（2GB内存/1vCPU），最高€704.99/月（128GB/32vCPU）。代价是不提供Windows、Edge VPS不含IPv6，且它是欧洲厂商，中文支持有限。

**超量降速继续用。** DMIT东京Tier 1系列套餐内有流量额度，超出后不停机，降到50–500Mbps继续跑；同机房的Premium系列则是超量直接暂停服务。这种设计对业务连续性友好，但“不限量”前面有个降速前提。

**低带宽不限量。** 华纳云日本云服务器标5Mbps专用带宽、不限流量，1核1G款¥54/月，大陆优化线路延迟约30–70ms。但页面上四个套餐全部显示“售罄”，只能当作价格参照：低价不限量的代价是带宽被压到5Mbps，和200Mbps完全不是一个量级。

**不限流量但限带宽。** LisaHost日本节点属于这一类：月流量不设上限、不额外计费，但带宽上限就是实际天花板。原生IP不限量Lite是200Mbps，Pro是500Mbps；ISP住宅系列200/500Mbps；IIJ系列只有100/200Mbps。按带宽换算，200Mbps满速跑一个月理论上限约64.8TB，500Mbps约162TB——这个数字是根据带宽推算的，不是官方承诺。

这个区别决定了后面的所有取舍：你买的不是“无限速度”，是“不超额计费”。

## 常见问题

**不限流量真的不限速吗？**
不限流量指不按GB计费、不额外收费，带宽上限仍然存在。原生IP不限量Lite是200Mbps，Pro是500Mbps，ISP住宅是200/500Mbps，IIJ只有100/200Mbps。

**流量超了会怎样？**
不限量套餐没有“超流量”这回事，任何时候都受带宽上限约束。按流量计费的套餐超出后按官方条款限速或停机，具体以下单页为准。

**住宅IP和原生IP的不限量差在哪？**
同为Lite档、同为200Mbps，ISP住宅贵501元/月，买的是IP的住宅属性，平台识别时更像家庭宽带用户。IIJ再进一步，是IIJ双ISP住宅IP，但带宽降到100Mbps，需要中转。

**能装Windows吗？**
支持，Windows授权可能需要额外费用，下单时确认。

**要不要开BBR？**
官方明确建议开启，跨国链路对带宽利用率提升明显。Linux几条命令即可，不开也能用。

**ping不通是不是坏了？**
IIJ系列的IP段被提供方禁了ping，ping不通是正常现象，不影响实际使用。
